# Support

Nora Framework is an independent, pre-stable project in active development. Support is provided on a best-effort basis by maintainers and contributors through the official repository.

## Where to get help

- **Documentation:** start with [README.md](README.md), [docs/INSTALLATION.md](docs/INSTALLATION.md), [docs/API_REFERENCE.md](docs/API_REFERENCE.md), and the `docs/` and `architecture/` directories.
- **Questions, bugs, and feature requests:** use [GitHub Issues](https://github.com/moravetech/nora/issues) when appropriate. Include reproducible steps, environment details, and relevant logs/output.
- **Security vulnerabilities:** do **not** report security issues in public issues. Follow [SECURITY.md](SECURITY.md).

## Support expectations

- Nora does not currently publish a guaranteed maintenance window, LTS policy, or response-time SLA unless explicitly stated in release materials.
- Compatibility and verification status vary by feature, PHP version, database, and environment. Refer to [README.md](README.md), [docs/TESTING.md](docs/TESTING.md), [RELEASE_POLICY.md](RELEASE_POLICY.md), and audit/release documents under `docs/` for evidence-based status.
- Before relying on a capability in production, validate it in your target environment (including configuration, database, deployment, and security controls).

## Contributions

See [CONTRIBUTING.md](CONTRIBUTING.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for contribution guidelines and community expectations.
